# Publishing a daily journal
1. Copy day-1.html to day-2.html (then day-3.html, etc.) in this same folder.
2. Replace the entry title, date, story and summary. Set data-day on .entry-navigation to its day number.
3. Keep journal.js and entries.js script tags, shared styles and branding.
4. Add the published file to entries.js with its day, date, title, description, file and minutes.
5. Publish both files together. Archive and previous/next links update from this list.
Do not list a file until it exists. The homepage portrait currently uses assets/img/Basanta_saru.jpg.
